Sobre o Wi-Fi da Fé

Um projeto acadêmico criado por estudantes da PUC-Campinas para facilitar o acesso a cursos, práticas de formação e prazos importantes.

O problema

Informações sobre cursos de graduação, práticas de formação e prazos ficam espalhadas entre e-mails institucionais, avisos e o site oficial da PUC — difícil de acompanhar e fácil de perder prazos importantes.

Nossa missão

Centralizar essas informações em um único lugar simples e acessível, para que qualquer estudante encontre o que precisa em segundos e nunca mais perca um prazo de inscrição ou matrícula.

Objetivos de Desenvolvimento Sustentável

ODS 4

Educação de Qualidade

Facilitamos o acesso à informação acadêmica, ajudando estudantes a aproveitar melhor as oportunidades de ensino.

ODS 9

Indústria, Inovação e Infraestrutura

Criamos uma infraestrutura digital simples para modernizar a comunicação entre a instituição e os estudantes.

Sobre este protótipo

O Wi-Fi da Fé é desenvolvido como Projeto Integrador (PI: Desenvolvimento de Sistemas Web, Turma 102). Nesta etapa, o projeto é inteiramente front-end (HTML, CSS e JavaScript): os dados de cadastro, login e cursos salvos ficam armazenados apenas no navegador de cada visitante (localStorage), sem banco de dados ou back-end.

Perguntas frequentes

Não. É um projeto acadêmico criado por estudantes na disciplina PI: Desenvolvimento de Sistemas Web. Os cursos e os prazos exibidos são dados de exemplo.

Somente no navegador que você está usando (localStorage e sessionStorage). Não existe servidor, banco de dados nem API: nada é enviado pela internet.

Porque a autenticação é uma simulação feita só no front-end. A senha é conferida apenas quanto ao formato e nunca é armazenada. Um sistema real validaria a senha em um back-end.

Abra o Perfil e use o botão "Excluir conta e dados locais". Isso remove a conta, os cursos salvos e as mensagens deste navegador.
